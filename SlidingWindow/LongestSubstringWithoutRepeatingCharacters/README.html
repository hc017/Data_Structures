Longest Substring Without Repeating Characters

Day 4 · Topic: Sliding Window · Daily DSA Challenge

Difficulty: Medium Pattern: Sliding Window Time: O(n) Space: O(min(n, charset))

🧩 The Problem

You're given a string s. Find the length of the longest substring that does not contain any repeating characters. 

Input:  s = "abcabcbb"
Output: 3   // the longest repeat-free substring is "abc"

📖 The Story

Imagine you're a bouncer at the door of a small party room. Guests walk in one at a time, but the room has one strict rule: no two guests with the same name can be inside at once.

The slow way: every time someone new arrives, check their name against every single guest already inside, one by one. With a big room that's a lot of checking.

The smart way: keep a sticky note of "who's currently inside and where they're standing." When a new guest arrives, glance at the note. If their name is already on it and that person is still in the room, walk to the door and start letting people out from the front of the line until that duplicate guest has left — then let the new guest in. If their name isn't in the room, just let them in and keep growing the room.

The "room" is your sliding window (left to right), and the sticky note is a HashMap (Java) / dict (Python) that remembers the last position each character was seen.

🌍 Real-Life Example

Think of a music streaming app's "no repeat" queue rule — it won't play the same song twice within your current listening session's recent window. As new songs are queued, the app checks if a track is already "active" in the recent window; if so, it trims older tracks off the front of the window until the repeat is gone, then keeps playing. It never re-scans the whole history — it just remembers the last time each song played and slides the window forward.

The "Yes" branch on the right shrinks the window by advancing left past the duplicate's last seen position before the window is updated and re-measured.

⚙️ Approaches Compared

ApproachTimeSpaceIdea
Brute ForceO(n³)O(min(n, charset))Check every substring, verify all characters are unique
Sliding Window (Optimized)O(n)O(min(n, charset))Expand right, shrink left past duplicates, track max window size

Why sliding window wins

Each character is added and removed from the window at most once, so the whole string is scanned in one pass.

Trade-off

Needs a small lookup table to remember where each character was last seen — a modest space cost for a big time win.
