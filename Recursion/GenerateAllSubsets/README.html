Generate All Subsets (Power Set)

Day 12 · Topic: Recursion · Daily DSA Challenge

Difficulty: Medium Pattern: Pick / Skip Backtracking Time: O(n · 2^n) Space: O(n) recursion

The Problem

Given an array of distinct integers nums, return every possible subset (including the empty one and the full array). A subset keeps some elements and drops others; order inside a subset does not matter.

Input:  nums = [1, 2, 3]
Output: [[], [1], [2], [1,2], [3], [1,3], [2,3], [1,2,3]]   // 2^3 = 8 subsets

The Story

Picture packing a small backpack for a trip. On your bed lie three items: a Torch, a Book and a Snack. You walk down the row one item at a time and ask a single yes/no question: "Do I take this one?"

Say yes or no to the Torch, then yes or no to the Book, then yes or no to the Snack. Every different string of answers is a different backpack. Three items with two answers each gives 2 × 2 × 2 = 8 backpacks, from the empty bag (said no to all) to the full bag (said yes to all).

Recursion does exactly this. At each item it first explores the world where you skip it, then steps back (backtracks), undoes the pick, and explores the world where you take it.

Real-Life Example

Think of a pizza topping picker on a food delivery app. With 5 toppings on offer, the kitchen's system may need to know every possible combination a customer could order (32 in total) to pre-compute prices or check ingredient stock. Feature flags work the same way: with n toggles, testers may want to try every on/off combination, which is the power set of the flags.

Logic Flow Chart

Each call splits into two child calls (skip and pick), so the recursion tree has 2^n leaves, one per subset.

Approaches Compared

ApproachTimeSpaceIdea
Bitmask (iterative)O(n · 2^n)O(n · 2^n) outputEvery number 0..2^n-1 is a pick/skip pattern; bit i decides nums[i]
Recursion + BacktrackingO(n · 2^n)O(n) stack + outputDecide skip/pick for each index, undo the pick after exploring it

Why 2^n is unavoidable

The answer itself has 2^n subsets, so no algorithm can be faster than writing them all out.

Key trick

Copy the current list when saving it, because the same list keeps changing as recursion continues.
